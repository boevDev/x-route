# X-Route v0.3.0

## Что нового

- Раньше при клике на переключатель DNS на всё время операции показывалась одна
  надпись «Применение…», и было непонятно — приложение работает или зависло.
- Теперь кнопка показывает, на каком именно этапе находится процесс:
  определение сетевого адаптера → подключение DNS-серверов (при выключении —
  возврат к автоматическому DNS) → очистка DNS-кэша → проверка результата.
- После успешного переключения на пару секунд появляется подтверждение:
  «DNS подключён» или «Автоматический DNS восстановлен», затем кнопка
  возвращается в обычное состояние.
- Если переключить DNS не удалось (например, нет прав администратора или нет
  подключения к сети), текст ошибки стал понятнее, а кнопка сразу доступна
  для повторной попытки.

## Как обновиться

Скачайте установщик ниже (`X-Route_0.3.0_x64-setup.exe` или
`X-Route_0.3.0_x64_en-US.msi`) и запустите его — установщик автоматически
заменит предыдущую версию.

⚠️ При первом запуске Windows SmartScreen может показать предупреждение
«Windows защитила ваш компьютер» — это ожидаемо для неподписанного
инсталлятора. Нажмите «Подробнее» → «Выполнить в любом случае».
